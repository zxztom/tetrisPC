# 原版 Blitz 冲分优化

2026-10-15。目标是原版 SOLO → BLITZ 单局完整两分钟的最高原生得分。保留 PC 搜索、纯四行及 4＋4＋6 DPC，比较新模式的收益，不把某一局高分解释为稳定水平。

## 本轮选择标准

最高分与完成率分开记录。优先减少每块实际耗时，尽早升级，并提高 PC、T-spin、消四的实际收益。finesse 用于减少多余操作与失误；它本身不直接扣分，因此不能仅为得到零 fault，默认放弃大量可完成的 PC。

固定等级 CUSTOM 用来验证地面操作、识别和锁定时间，不参与原版最高分排名。独立新局走 HOME 菜单，不用 AGAIN/R；全部失败和重开原因保留，不拼接跨局得分，不向在线程序提供种子或历史录像未来。

## 已找到的原生高重力问题

上一轮完整两局中的第二局原生为 1,595,011 分、515 块、Level 14、5 faults。原生 frame 6900 检查点为 494 块、0 faults，frame 7200 为 515 块、5 faults。控制器验证了 514 块；最后一块为结束前预留窗口中的自然锁定，已单列。

同一历史地形的最短地面动作复核：第 499 块起进入模型的 20G 段，499–514 共 16 个控制落点。其中 502 J、504 S、509 Z、513 J 四个落点分别需要 1、1、1、2 个额外参考输入，合计 5，与最后检查点区间的原生增量一致。这里只能确认区间总量吻合，不能用每五秒一个的检查点证明逐块归因。

全局参考预算与原生统计并不相同：低重力的软降、空中路线和豁免会改变原生判断。不能用离线估计的百分比冒充原生 finesse。

原始证据：`output/blitz-high-gravity-fault-interval-audit.json`、`output/farm-20261015-123912-518f97e1/attempt-00002.ttr`。

## 可选的高重力少按键策略

新增 `gravity`，界面名“高重力少按键”：实际重力低于 20G 时保留 balanced 的 PC 优先；进入 20G 后用 strict 的标准按键预算。切换时丢弃切换前的 PC 动作缓存，按实际棋盘重新规划。CUSTOM 固定等级使用实际模拟档位判断，不把计分等级 1 当成低重力。

这与路线计算缓存不同：丢弃的是旧按键政策下的待执行计划；几何计算的缓存仍必须与当前棋盘、朝向、SRS+ 踢墙、Hold 后姿态及限制完全一致。

## 执行开销优化

上一轮 514 个控制落点平均执行 182.08ms，实际按键占 67.90ms；高重力最后 16 块平均执行 191.63ms。整局 4.29 PPS，不能只用规划耗时倒数声称达到 6 PPS。

本轮实现：

- 重复地面路线计算缓存，最多 512 项，键包含棋盘、实际稳定姿态、踢墙表内容、目标、旋转奖励和所有输入限制。返回独立副本，避免调用方修改动作污染下一次计算。几何缓存不会缓存未知来块，也不会替代硬降前后的画面核对。
- 实时 session 快照使用紧凑 JSON，结束与失败文件继续保留便于阅读的格式；逐块 JSONL 照常写入。
- PC 截图使用更快的无损 PNG 压缩，像素保持一致。
- 记录路线缓存命中和落地后的记录耗时，供下一轮识别真正瓶颈。

历史地面查询重复计算基准 584 次，缓存前总 264.81ms，后 143.52ms，逐个动作、落点及 spin 完全一致。这部分整局只节省约 121ms，不能夸大成大幅提速。

同一真实 session 内容的十次本机序列化中位数：缩进 JSON 31.43ms → 紧凑 JSON 8.13ms。相同 PC 截图十次无损编码中位数：28.12ms → 8.35ms，文件 270KB → 467KB。这是在下一块锁定窗口内减少阻塞的改动，尚不能单凭微基准量化原生 PPS 增益。

原始结果：`output/ground-cache-historical-benchmark.json`、`output/recording-overhead-benchmark.json`。

## 冲分实验：地形覆盖率与收尾得分

增加独立的 `score` 策略，不替换旧档。它保留 4＋4＋6 的 DPC 接续与完整可见收尾检查，空场优先尝试已有的高覆盖四块地形，不强制优先搭传统七块 PCO。求解器作者曾给出传统 PCO 放入 I 后的特定条件成功率 61.19%，并提醒应结合留下来的块再选地形；这是改进候选选择的依据，不能套用成当前所有随机起手的成功率。[knewjade 的连续 PC 研究](https://gist.github.com/knewjade/79b6bac0b03bc059ee1b0ab1bd4d7c3a)。

原计分收尾仍先比较额外按键预算、DPC 携带块，再比较得分。新档在已经找到、独立验证的 PC 收尾上，用剩余预算比较更高的消行分，按键数作为后续取舍；搜索超时保留原收尾。选择 strict 或进入 gravity 的高重力阶段时，仍受零额外参考输入限制，最后一块也不得突破预算。

真实历史地形第 82–85 块提供了回归实例：原少按键收尾到 119,900 分、0 额外参考输入；可达的另一完整 PC 到 120,400 分、2 个额外参考输入。这是几何和计分模型的取舍，不能直接说原生一定多 2 faults。两种路线均独立重放到同一空场；零预算下新档仍不得使用该例外。
