# Blitz打完自动下一局

在实验室选择“Blitz得分策略”，勾选“自动刷分”，打开“每局打完后自动开始下一局（新的随机队列）”。“尝试局数”设0会持续，设2会完成两局后停止。取消自动下一局则保存当前完整局后停止。PC搜索、4＋4＋6 DPC、各按键策略及速度档都可继续选择。

启动前把TETR.IO停在HOME主页、BLITZ启动页或已结束的结果页，选择原版SOLO → BLITZ、120秒。程序会识别这三个入口并自行进入新的首局。每局结束先下载原生录像、核验两分钟、已核对的落子及原生硬降事件，再返回HOME，经SOLO → BLITZ → START进入下一局。不会点击AGAIN，也不按R重复同队列。

F8、Esc、界面停止按钮或切走游戏均停止。未确认实际落点、整盘、菜单或录像时停止整个任务；不会把执行故障当成“不顺”自动重试。桌面要保持解锁、游戏保持前台。

每个`output/farm-日期-编号`目录保留：

- `attempts.jsonl`与`summary.json`：逐局状态、原因、块数、PC、耗时、原生成绩与最高完整局。
- `attempt-00001.ttr`等：每个完整局的原生录像。最高分取一局原生成绩，不累加跨局分数。
- `menu-*.png`：菜单核对证据。失败留下`navigation-stop.json`及对应截图。

下一局的至少35个已观察来源若与上一局相同，就停止复核随机入口；不读种子或未来队列。只比较前35块，避免不同最终块数掩盖重复队列。

当前已校准完整局的菜单与保存对话框。提前放弃的导航仍未校准，对应无PC、断链、低收益条件暂禁用，默认都关闭；这不影响打满两分钟后的自动下一局。界面显示已记录局数、完整局数、最高完整局原生分。

菜单操作先把指针放到空白背景，等待悬停动画结束，再用两个文字区连续核对后点击。校准图片位于`output/farm-navigation`，改窗口比例或菜单语言可能需要重新校准；不匹配就停止。

命令行等价用法：`scripts/run-blitz.py --farm --attempts 2`。`--attempts 0`持续；`--stop-after-complete`在第一局完整结束后停止。CLI默认也关闭提前放弃条件。

临近结束会预留600ms停止发出新硬降。20G时下一块可能在这段时间自然锁定：只有原生硬降次数恰等于已核对落子、且仅多出一块时才接受，并单记natural_tail_pieces=1；不把它计作程序控制块。其他块数差异仍停止。
