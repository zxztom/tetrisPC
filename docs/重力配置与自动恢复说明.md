# 重力、操作配置与断链恢复

版本 0.6.0，实机核对日期 2026-10-14。

## 如何使用

1. 双击“启动PC实验室.cmd”。选择纯四行七次循环或 4＋4＋6 循环。
2. 若改过游戏按键，在 TETR.IO 的 CONFIG → EXPORT SETTINGS 导出 `.TTC`，在实验室的“当前操作配置”中选择它。程序支持 GUIDELINE、WASD、自定义键盘绑定；不会读取账号登录信息。
3. 想加速时点“生成加速配置”，下载文件，拖进 TETR.IO 导入，再点“已导入游戏，应用此配置”。原按键、显示和声音设置保留，处理参数改为 ARR=0、DAS=6F、DCD=0、SDF=∞。本次已在客户端应用这些参数，原设置有备份。
4. 操作间隔建议先用 20ms。它是松键到下一次按键的最短间隔；截图识别、等待动画和求解也占时间。有限锁定延迟下的旋入组合要求间隔不超过 100ms。
5. 若希望一直尝试，勾选“PC 无法继续时清空 / 重开并持续尝试”，把恢复次数及循环次数都设为 0。配置会保存，快捷启动器也会使用。
6. 打开单人、七袋、无垃圾练习，保持游戏在前台，从空场开始。短按 F8 / Esc 或切走游戏会停止；网页“停止”也可取消。

修改游戏里的按键或 handling 后，要重新导出并载入当前配置。实验室读取的是选定的导出文件；不会自动知道你随后在游戏中改了什么。

## 有重力时的操作

每张截图先减去已核对的固定堆积，剩下的四格用于定位正在下落的块。不是一直假定它停在出生高度。每步按实际高度重新计算合法路线，移动核对允许自然下降，硬降前核对投影。

能直接空中旋转、移动后硬降的落点，优先这样执行。必须旋入时，先验证整组动作，再把瞬降、移动和旋转快速连起来；最终投影与落地棋盘分别核对，避免在约半秒的锁定窗口里做多次截图。玩家也可以按相同动作顺序执行：空中先摆方向和列，瞬降后立即做需要的移动 / 踢墙旋转，再硬降。

ARR=0 的贴墙使用一次按住移动键，等待 DAS 充满后到墙，随后松开。SDF=∞ 的软降立即落到底而不主动锁定，给旋入留下机会。相关处理规则见 [TETR.IO 官方 mechanics](https://tetrio.github.io/faq/mechanics.html)；导出与标准键盘方案见 [TETR.IO CONFIG](https://tetr.io/)。

## 自动恢复如何计数

没有找到可执行 PC，或自然下落使原落点不可达时，打开恢复选项的程序会重新尝试。搜索超时或有限预览找不到方案，并不等于数学上证明无解。

ZEN 使用配置里的重试键，只清当前棋盘并重新识别块序，保留等级、累计分数；不会点击 SOLO → ZEN 的 RESET。CUSTOM 使用重试键重开当前随机练习。每次恢复保留独立记录，已经完成的 PC 不会和下一次尝试拼成不断链的成绩。无法可靠识别、意外横移、失去焦点及停止指令仍会停止。
